# Current lighting handoff

The homeowner-facing current set is in [`current/`](current/) and starts at
[`handoff/index.html`](../../index.html). It includes the lighting workbench,
three differentiated plan PDFs, schedules, the fixed-CCT map, inherited
heatmap summary, and room/building load sheet.

The files at this directory level are retained source calculations and
historical verification inputs for reproducibility. They are not a second
current handoff and should not be used to replace the PDFs and data in
`current/`. The optical results remain estimates; no new photometric run,
product approval, or construction release is implied.
